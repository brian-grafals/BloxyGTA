# BloxyGTA — Game Design Document

## What Is This Game?

BloxyGTA is a 3D open-world crime game — kind of like GTA 5 freemode, but simpler and made by us. You play as a blocky criminal running around a city, doing whatever you want.

## Prototype — What We Built First

Just the basics so we can make sure movement feels good:

- **Player** — a red box (placeholder for a real character later)
- **Floor** — a big gray platform to run around on
- **Test Dummy** — a black box standing in front of you
- **Camera** — third-person, rotates with your mouse
- **Shooting** — right-click to aim, left-click to shoot
- **Dummy Explosion** — shoot the dummy and it blows up into red cubes! 💥

| Left Mouse | Shoot |

---

## Art Style

Blocky/low-poly look — like Roblox but in Godot. Simple colored boxes for now, real models later.

---

## The Story (rough idea)

You're a criminal in a big city. You can do jobs, steal cars, run from cops, or just mess around. No missions yet — just freemode chaos. Think GTA Online but way more blocky.
